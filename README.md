# Signal Processing Labs

A collection of audio and signal-processing laboratory exercises developed as part of the Systems I coursework at Universitat Pompeu Fabra (UPF).

The repository contains Python and Jupyter Notebook work covering the analysis and processing of digital audio signals, with reusable utilities for visualization and frequency-domain analysis.

## Overview

The labs explore topics including:

- Discrete-time signals
- Audio loading and processing
- Time-domain representation
- Fourier analysis
- Frequency-domain representations
- Spectrograms and time-frequency analysis
- Frequency responses
- Zeros and poles
- Digital filtering concepts
- Audio synthesis and reconstruction

The repository also contains WAV files used for experiments and comparisons.

## Audio analysis utilities

The shared utilities include functions for:

- Loading and saving audio
- Converting stereo signals to mono
- Removing the DC component
- Plotting signals in the time domain
- Visualizing spectrograms
- Inspecting spectra at specific times
- Visualizing complex values
- Plotting frequency responses
- Visualizing zeros and poles

## Audio material

The repository includes WAV files used for experimentation, including reference recordings and synthesized signals such as guitar recordings and generated audio.
